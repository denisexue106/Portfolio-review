# Denise Barrett · Portfolio review

The public copy of my portfolio review deck: three case studies in product design,
design systems and AI, from my work at Keap, acquired by Thryv.

**Open it:** https://denisexue106.github.io/Portfolio-review/

The review is password protected, and the password comes with the link I send. The
page holds the deck encrypted, so nothing in this repository is readable without it.

- Arrow keys or the dots on the right move between slides.
- Press `N` to open the speaker notes in their own window.
- Press `E` for Edit mode, where each case study can be set to Deep, Quick or Off.
- A link can set that for you: `?deep=form&quick=business` shows Form Unification in
  depth and a quick look at Business Listing. The keys are `form`, `branding` and
  `business`.

This copy leaves out confidential material from the version I present in person:
vendor names, contract values, internal usability scores, internal web addresses, and
images of real customers or colleagues. Portfolio site: https://dbyxdesign.com
